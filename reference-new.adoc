= Was ist neu in Cloud Volumes ONTAP 9.18.1
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Sie können jetzt Cloud Volumes ONTAP 9.18.1 bereitstellen und aktualisieren. Sie können die Basisversion dieser Version und die neuesten Patch-Versionen, die für die Bereitstellung und das Upgrade verfügbar sind, in der Console einsehen.

Informationen zu den Cloud Volumes ONTAP-Funktionen, die in den neuesten Versionen der NetApp Console eingeführt wurden, finden Sie unter Neuerungen in https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/whats-new.html["Cloud Volumes ONTAP"^].



[[9-18-1-p8-30-october-2026]]
== 9.18.1 P8 (30. Oktober 2026)

Der Cloud Volumes ONTAP 9.18.1 P8 Patch ist jetzt für die Bereitstellung und das Upgrade in AWS, Azure und Google Cloud verfügbar. Die Konsole fordert Sie auf, Ihre bestehenden Systeme auf diese Patch-Version zu aktualisieren.

link:https://mysupport.netapp.com/site/products/all/details/cloud-volumes-ontap/downloads-tab/download/62632/9.18.1P8["Sehen Sie sich die Liste der im P8 Patch behobenen Fehler an"^] (NetApp Support-Website-Anmeldung erforderlich).

== 9.18.1 P3 (22. Juli 2026)

Der Cloud Volumes ONTAP 9.18.1 P3 Patch ist jetzt für die Bereitstellung und das Upgrade in AWS, Azure und Google Cloud verfügbar. Die Konsole fordert Sie auf, Ihre bestehenden Systeme auf diese Patch-Version zu aktualisieren.

link:https://mysupport.netapp.com/site/products/all/details/cloud-volumes-ontap/downloads-tab/download/62632/9.18.1P3["Sehen Sie sich die Liste der im P3 Patch behobenen Fehler an"^] (NetApp Support-Website-Anmeldung erforderlich).



[[9-18-1-p2-30-april-2026]]
== 9.18.1 P2 (30. April 2026)

Der Cloud Volumes ONTAP 9.18.1 P2 Patch ist jetzt für die Bereitstellung und das Upgrade in AWS, Azure und Google Cloud verfügbar. Die Konsole fordert Sie auf, Ihre bestehenden Systeme auf diese Patch-Version zu aktualisieren.


NOTE: Für AWS ist Cloud Volumes ONTAP 9.18.1 P2 die Standardversion für Bereitstellung und Upgrade. Jede niedrigere Version oder jeder Patch von 9.18.1 wird nicht unterstützt.

link:https://mysupport.netapp.com/site/products/all/details/cloud-volumes-ontap/downloads-tab/download/62632/9.18.1P2["Sehen Sie sich die Liste der im P2 Patch behobenen Fehler an"^] (NetApp Support-Website-Anmeldung erforderlich).

[[9-18-1-ga-10-february-2026]]
== 9.18.1 GA (10. Februar 2026)

Die Cloud Volumes ONTAP 9.18.1 General Availability-Version ist jetzt für die Bereitstellung und das Upgrade in Microsoft Azure und Google Cloud verfügbar.


NOTE: Diese Version ist nicht für die Bereitstellung und das Upgrade in Amazon Web Services (AWS) verfügbar.



[[upgrade-notes]]
== Upgrade-Hinweise

Lesen Sie diese Hinweise, um mehr über das Upgrade auf diese Version zu erfahren.



[[how-to-upgrade]]
=== So führen Sie ein Upgrade durch

Upgrades von Cloud Volumes ONTAP müssen über die Console durchgeführt werden. Sie sollten Cloud Volumes ONTAP nicht mit dem System Manager oder der CLI aktualisieren. Dies kann die Systemstabilität beeinträchtigen.

link:http://docs.netapp.com/us-en/bluexp-cloud-volumes-ontap/task-updating-ontap-cloud.html["Erfahren Sie, wie Sie ein Upgrade durchführen, wenn die Console Sie benachrichtigt"^].



[[supported-upgrade-path]]
=== Unterstützter Upgrade-Pfad

Sie können auf Cloud Volumes ONTAP 9.18.1 von den 9.17.1 P1 und späteren Patches in AWS, Azure und Google Cloud aktualisieren. Die Konsole wird Sie auffordern, berechtigte Cloud Volumes ONTAP Systeme auf diese Version zu aktualisieren.



[[downtime]]
=== Ausfallzeit

* Das Upgrade eines Einzelknotensystems nimmt das System für bis zu 25 Minuten offline, währenddessen werden die I/O-Vorgänge unterbrochen.
* Das Upgrade eines HA-Paar-Systems erfolgt unterbrechungsfrei und die I/O bleibt ununterbrochen. Während dieses unterbrechungsfreien Upgrade-Prozesses wird jeder Node nacheinander aktualisiert, um weiterhin I/O für Clients bereitzustellen.
